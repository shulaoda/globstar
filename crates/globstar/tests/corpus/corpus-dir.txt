# ============================================================================
# corpus-dir.txt — match_dir golden test corpus
# Format: PATTERN<TAB>DIR_PATH<TAB>EXPECTED[<TAB>FLAGS]
# EXPECTED: pruned | descend | match | descend-match | descend-all |
#           descend-all-match
#   pruned            = no descendant can match; the walker skips the whole subtree
#   descend           = descendants may match; keep walking down
#   match             = the directory itself matches; no descendant matches
#   descend-match     = the directory matches AND descendants may match too
#   descend-all       = the directory doesn't match, EVERY descendant does
#   descend-all-match = the directory matches AND every descendant does
# The two `-all` results need dot=true: under dot=false no wildcard matches
# the dot-led names below, so a subtree is never fully covered.
# See tests/README.md for format details
# ============================================================================
