# corpus-multi.txt — multi-pattern OR matching golden corpus
# Format: PATTERNS_JSON<TAB>PATH<TAB>EXPECTED[<TAB>FLAGS]
#
# PATTERNS_JSON  JSON array of pattern strings combined via OR; any
#                row matching at least one pattern reports "match".
# EXPECTED       match | no-match
# FLAGS          k=v[,k=v]; defaults dot=true, case_insensitive=false
#
# Negation (`!`-prefix patterns) is exercised in the single-pattern
# corpus; this file stays positive-only because Rust's `Glob::union`
# rejects `!`-prefixed members and we want every row to drive both
# runtimes through the same surface.
# ============================================================================

## empty.brace.factoring
# Factoring `{}`-bearing members leaves an empty branch; the union still
# compiles (one in-segment NFA) and matches as its members do.
["**{}","**{*}"]	a{}	match
["**{}","**{*}"]	{}	match
["**{}","**{*}"]	a{b}	match
["**{}","**{*}"]	x	no-match
["{}**","{a}**"]	{}x	match

## union.factored-suffix.leading-seps
# Factoring a shared trailing `**/` leaves an empty branch whose expansion
