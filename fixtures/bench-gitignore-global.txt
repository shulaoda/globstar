# alafourcadev/ultimate-gitignore): 392 file names and extensions
# anywhere (`**/name`, `**/*.ext`), 163 directories (`dir/**`, 141 of
# them anywhere) and 31 rooted entries. The translation: a line with no
# `/` but a trailing one matches at any depth and gets `**/` in front;
# a line with a `/` before its end is rooted, and loses a leading `/`;
# a trailing `/` becomes `/**`; the 22 negations (`!`) are dropped,

# an earlier one after the rewrite. The 5 members wax cannot parse (a
# `:`, `\#`, `$` or `,`) are dropped too, so every library matches the
# same set through its own set API: `**/Thumbs.db:encryptable`,
